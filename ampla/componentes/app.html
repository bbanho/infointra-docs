App.tsx — Raiz e Rotas ​

Arquivo: src/App.tsx · Símbolos codegraph: 9 · Papel: bootstrap de rotas da SPA

Responsabilidades ​

  1. Monta o BrowserRouter e define as rotas da aplicação.
  2. A rota / renderiza o MainApp (app completo de vendas).
  3. A rota /docs é protegida e lazy-loaded:
tsx
export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<MainApp />} />
        <Route
          path="/docs"
          element={
            <ProtectedRoute>
              <Suspense fallback={<Spinner />}>
                <DocsViewer />
              </Suspense>
            </ProtectedRoute>
          }
        />
      </Routes>
    </BrowserRouter>
  );
}

Decisões de engenharia ​

DecisãoMotivo
React.lazy + Suspense no /docsChunk separado — protege o conteúdo de documentação e reduz o bundle inicial
ProtectedRoute em voltaAcesso à documentação exige auth (isAuthenticatedForDocs) — proteção de IP
Rotas curtas (/, /docs)SPA de força de vendas: navegação por abas internas no MainApp, não por URLs profundas

Dependências ​

  • MainApp.tsx — app principal
  • DocsViewer.tsx — documentação interna (lazy)
  • ProtectedRoute.tsx — guard de autenticação
  • react-router-dom v7
