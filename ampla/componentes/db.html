db.ts — Camada de Persistência (Dexie/IndexedDB) ​

Arquivo: src/db/db.ts · Símbolos codegraph: 13 · Licença: Apache-2.0

AmplaVendasDatabase ​

Classe que estende Dexie e define o schema do banco local:

ts
export class AmplaVendasDatabase extends Dexie {
  clients!: Table<Client, number>;
  products!: Table<Product, number>;
  orders!: Table<Order, number>;
  syncLogs!: Table<SyncLog, number>;

  constructor() {
    super('AmplaVendasProDB_v2');
    this.version(1).stores({
      clients: '++id, tipo, razaoSocial, cpfCnpj, cidade, status',
      products: '++id, sku, nome, categoria, isService, ativo',
      orders: '++id, codigoPedido, dataCriacao, statusSync, clientId, vendedorId',
      syncLogs: '++id, dataHora, tipo, status',
    });
  }
}

export const db = new AmplaVendasDatabase();

O nome AmplaVendasProDB_v2 carrega versão — schema changes futuros incrementam version(2).stores(...) com migrações Dexie.

Popula clientes de exemplo (TecSul, Horizonte Construções, etc.) e catálogo somente se o banco estiver vazio (clients.count() === 0). É o mecanismo da demo e do reset.
