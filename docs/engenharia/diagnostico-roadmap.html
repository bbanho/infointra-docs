Diagnóstico & Roadmap de Engenharia ​

Resumo executivo do diagnóstico original (docs/06-diagnostico-e-plano-de-engenharia.md) — o que o protótipo já entrega e o que falta para produção.

Roadmap sugerido (sprints) ​

Sprint 1 — Fundação de segurança ​

  • [ ] Supabase Auth + RLS em todas as tabelas (políticas por auth.uid()).
  • [ ] Remover senha ampla2026 e PINs em texto plano → hash + perfis gerenciados.
  • [ ] VITE_SUPABASE_* obrigatórias no build de produção; remover credenciais de localStorage em prod.

Sprint 2 — Integração ERP real ​

  • [ ] Microserviço middleware Adapter (Node/Go) com os 4 adaptadores (SAP, TOTVS, Senior, Linx).
  • [ ] Substituir o REST simulado do ErpSyncCenter pela chamada real.
  • [ ] Retry com backoff exponencial + DLQ persistente.

Sprint 3 — Testes e CI ​

  • [ ] Vitest para formatters.ts e supabaseAndFiscal.ts (chave 44 dígitos, DV módulo 11, XML).
  • [ ] Playwright E2E: fluxo completo de venda offline → sync → export.
  • [ ] CI (GitHub Actions): lint + test + build.

Sprint 4 — Resiliência de sync ​

  • [ ] Service worker com Background Sync (fila persistente entre sessões).
  • [ ] Detecção de conflitos por updated_at (last-write-wins temporal).
  • [ ] Delta sync via syncLogs.
